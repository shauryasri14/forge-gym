# Forge — gym tracker (PWA)

Installable, offline web app for Android (Chrome → ⋮ → **Install app**). No build step, no server code.

- **876 exercises** from [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain): muscles, equipment, level, step-by-step instructions. Search + filters + favourites, and your own custom exercises.
- **3D muscle animations**: a stylised 3D muscular body (three.js, `js/body3d.js`) performs each exercise with the right equipment. The 17 muscle groups are separate meshes; **primary muscles glow red and pulse with the effort of each rep, secondary muscles glow orange**. Drag to rotate, pinch to zoom, or jump to 3/4 · Front · Side · Back. Each exercise is mapped to one of ~85 movement patterns (`js/anim.js`); list thumbnails are rendered from the same model.
- **Form videos**: "Watch form video" opens a YouTube search for the exercise, or a specific video link you save per exercise.
- **Anatomy videos**: an "Anatomy video" card plays anatomically accurate muscle animations from the [Anatomy Standard](https://www.youtube.com/@anatomystandard) channel inside the app, using YouTube's embed player (loaded only on tap, never copied). `data/videos.json` maps exercise id → YouTube id; exercises without one get a "Find on Anatomy Standard" button, and any pasted YouTube/Shorts link is embedded the same way.
- **Workout logger**: sets × weight × reps with last session's numbers as placeholders, rest timer (vibrates + beeps), routines, repeat a past workout, PRs, est. 1RM and a progress chart per exercise. Keeps the screen awake while logging.
- **LeetCode-style consistency panel**: a year heatmap grouped by month (colour = sets that day), workouts in the past year, total active days, max/current streak, weekly-goal streak, badges. Tap a day to see it or mark it active.

Data lives in `localStorage` on the phone (key `forge.v1`); Settings → Export/Import backup moves it between devices.

## Run locally
```
python -m http.server 8000        # then open http://localhost:8000
```

## Put it on your phone
A service worker (needed for install + offline) only runs over **HTTPS** (or localhost), so host the folder on any static HTTPS host, open it in Chrome on the phone once, and choose **Install app**. After that it works offline.
- GitHub Pages / Cloudflare Pages: publish this folder as-is.
- Tailscale: `tailscale serve --bg 8000` while `python -m http.server 8000` runs, then open the `https://<laptop>.ts.net` URL on the phone.

When you change any file, bump `VERSION` in `sw.js` so installed copies update (the app shows "Update ready · Reload").

## Files
| | |
|---|---|
| `js/app.js` | router (`#/home`, `#/library`, `#/ex/<id>`, `#/workout`, `#/history[/<id>]`, `#/settings`, `#/custom[/<id>]`) and all views |
| `js/store.js` | state, persistence, units (stored in kg), derived numbers |
| `js/consistency.js` | heatmap, streaks, badges |
| `js/anim.js` | keyframe `PATTERNS` library, FK/IK pose solver (2D joints), `poseAt()` timing + rep effort |
| `js/body3d.js` | 3D muscle body, equipment/props, `Viewer` (orbit, play), shared offscreen thumbnail renderer |
| `vendor/three.module.min.js` | three.js r160 (MIT, `vendor/three.LICENSE`), bundled so the app works offline |
| `data/exercises.json` | generated by `tools/build_data.py` |
| `sw.js`, `manifest.webmanifest`, `icons/` | PWA bits (`tools/make_icons.py` redraws the icons) |

## Tools
- `python tools/build_data.py [exercises.json] --report` — rebuild the exercise list and print which animation each exercise got (rules are regexes on the name, first match wins).
- `tools/preview.html?hold=barbell&cols=4&only=squat,bench&pm=chest` — every pattern's working pose as a 3D thumbnail (serve the folder, open in a browser). `python tools/shot.py "tools/preview.html?..." out.png` screenshots it.
- `python tools/stage_shots.py out.png <exercise_id>...` — close-ups of the 3D stage from 3/4, Front and Back, tiled.
- `python tools/smoke.py <out_dir> [--light]` — phone-size run through every screen with Edge + Playwright on seeded fake data; saves screenshots and prints console errors.

Pose angles in `anim.js` are degrees from straight down, positive toward the way the figure faces (0 down, 90 forward, 180 up). Side-view poses can't tell face-up from face-down, so lying-on-your-back patterns carry `supine: true`; the 3D body rolls over for those.
